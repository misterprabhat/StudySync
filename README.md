## ✨ Overview

**StudySync** is a modern, responsive, and feature-rich web application built for students and self-learners who want to organize their academic life more effectively.

From managing multiple subjects and prioritizing daily tasks to tracking learning progress and monitoring deadlines, StudySync brings everything together in one intuitive dashboard.

Whether you're learning programming, preparing for examinations, or developing new technical skills, StudySync helps you stay organized, focused, and consistent.

## 🚀 Key Features

### 📊 01. Interactive Dashboard
- Get a centralized overview of your study activities.
- Monitor total tasks, completed tasks, pending tasks, and overdue items.
- View upcoming deadlines and active subjects.
- Track your overall productivity through visual statistics.

### 📚 02. Subject & Progress Management
- Manage 10+ core computer science and programming subjects.
- Track individual subject completion using visual progress rings.
- Monitor your learning journey across:
  - C Programming
  - Java
  - Python
  - JavaScript
  - Data Structures & Algorithms (DSA)
  - System Design
  - Operating Systems (OS)
  - Database Management Systems (DBMS)
  - Computer Networks (CN)
  - SQL

### ✅ 03. Smart Task Management
- Create and organize study tasks effortlessly.
- Assign tasks to specific subjects.
- Set priorities: High, Medium, and Low.
- Add deadlines to stay on schedule.
- Mark tasks as completed or delete them when no longer needed.

### 🔎 04. Search & Filtering
- Quickly find tasks using the search functionality.
- Filter tasks based on subjects and completion status.
- Organize your workload and focus on what matters most.

### 🌙 05. Dark & Light Themes
- Switch seamlessly between dark and light modes.
- Enjoy a comfortable viewing experience in different lighting conditions.
- Automatically retain your preferred theme using browser storage.

### 💾 06. Persistent Data Storage
- Automatically save tasks, subjects, and preferences.
- Utilizes the browser's `localStorage` API.
- Your study data remains available even after refreshing or reopening the application.
- No external database or backend configuration required.

### 📱 07. Responsive User Interface
- Modern and visually appealing interface.
- Responsive layouts for desktops, tablets, and mobile devices.
- Smooth transitions, clean components, and intuitive navigation.

## 🛠️ Technology Stack

StudySync is developed entirely using native frontend technologies without relying on external frameworks or complex build tools.

| Technology | Purpose |
|:---|:---|
| **HTML5** | Application structure and content |
| **CSS3** | Styling, layouts, themes, animations, and responsiveness |
| **JavaScript (ES6+)** | Application logic, task management, and DOM manipulation |
| **localStorage API** | Client-side data persistence |

## ⚡ Getting Started

Getting StudySync up and running is simple. Since the project uses vanilla HTML, CSS, and JavaScript, there is no need to install dependencies, configure a backend, or run complicated build commands.

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/studysync.git
```

### 2. Navigate to the Project Folder

```bash
cd studysync
```

### 3. Launch the Application

Open `index.html` directly in your preferred web browser.

**Recommended:** Open the project in [Visual Studio Code](https://code.visualstudio.com/) and use the Live Server extension for a smoother development experience.

That's it! Your StudySync dashboard is ready to use. 🎉

## 🔐 Data & Privacy

StudySync uses browser-based `localStorage` to save application data.

- No account registration is required.
- No external database is used.
- Study information is stored locally in the browser.
- Data persists across browser sessions on the same browser and device.

**Note:** Clearing browser storage or site data may permanently remove your saved StudySync information.
